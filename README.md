# MetaboNet CGM Forecasting — project page

A single-page project website for our MetaboNet Glucose Prediction Challenge work:
data audit, preprocessing, method, every result (public test set and
leave-one-study-out), every negative result, the leaderboard submissions, and an
interactive atlas of raw patient records.

It is plain HTML, CSS and JavaScript. There is no build step to serve it, and it
also works when `index.html` is opened straight from disk.

## Publish on GitHub Pages

1. Create a new repository on GitHub (for example `metabonet-cgm`).
2. Upload the **contents** of this folder to the repository root, so that
   `index.html` sits at the top level next to `static/`.
   Command line:
   ```bash
   git init
   git add .
   git commit -m "Project page"
   git branch -M main
   git remote add origin https://github.com/<user>/<repo>.git
   git push -u origin main
   ```
3. On GitHub: **Settings → Pages → Build and deployment → Source: Deploy from a
   branch → Branch: `main` / `(root)` → Save**.
4. After a minute the site is live at `https://<user>.github.io/<repo>/`.

The empty `.nojekyll` file tells GitHub Pages to serve the files as they are.

## De-anonymise after review

Everything identifying lives in one file: **`static/js/site-config.js`**.
Set `anonymous: false` and fill in the `named` block (authors, affiliations,
team name, acknowledgements, BibTeX author). Set `links.paper` and `links.code`
when they exist; a link left as `"#"` shows as a disabled "coming soon" badge.

## Folder layout

```
index.html                  the page
static/css/style.css        styles (colour tokens at the top; light and dark)
static/js/site-config.js    authors, links, BibTeX  <- edit this to de-anonymise
static/js/main.js           sortable tables, metric toggles, model arena, atlas explorer
static/data/results.js      generated from static/tables/metabonet_results.csv
static/images/*.png         figures, generated by tools/make_figures.py
static/tables/              every CSV / XLSX behind the tables and figures
static/atlas/               interactive patient atlas (plotly, opens standalone)
tools/                      scripts that regenerate data, figures and index.html
```

## Regenerate after results change

Edit the CSVs in `static/tables/` (or replace `metabonet_results.csv` with a new
output of `scripts/55_results_report.py`), then:

```bash
pip install pandas matplotlib openpyxl
python tools/build_data.py      # CSV -> static/data/results.js
python tools/make_figures.py    # CSV + measured constants -> static/images/
python tools/assemble.py        # tools/parts/*.html + tables -> index.html
```

Edit page text in `tools/parts/*.html`, not in `index.html`, which is overwritten
by `assemble.py`.

When the annual competition scores are released, add them to
`tools/parts/08_submissions_atlas.html` (the "Annual results" callout) and re-run
`assemble.py`.

## Data notice

The patient atlas renders de-identified records from the MetaboNet release
(Wolff et al., *J Diabetes Sci Technol*, 2026, doi:10.1177/19322968261441637).
Reuse of the underlying data is governed by the MetaboNet terms of use. Do not
attempt to re-identify any individual.

## Size

About 31 MB in total, of which 28 MB is the patient atlas (129 figures sharing
one 4.3 MB `plotly.min.js`). GitHub Pages serves this without issue.
